# docs/archive — frozen design history

These are frozen design-history artifacts from the v1 → v2 → v3 grammar evolution.

The v2 direction (intent grammar, lanes/streams, Score IR) was designed and validated
on paper — see `phase0-validation.md` — but **never built**; v3 leapfrogged it. The
shipped grammar is `../spec-grammar-v3.md`, and the as-built reference is
`../visuals.md`.

Files here reference since-deleted code (`pattern_parser.h`, `builtin_patterns.cpp`,
`render_preset.*`) and each other by pre-archive paths. They are kept for
**provenance, not reference** — do not update them, and do not cite them as current.
