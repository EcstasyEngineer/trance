# Historical design and investigation archive

The supported language is the [V4 grammar](../spec-grammar-v4.md). Start with the
[repository README](../../README.md) for playback, composition and build steps.

Historical documents remain at their original paths so review cross-references
and source evidence remain inspectable. Their banners mark them as development
records rather than current instructions. Older reports can describe defects
subsequently repaired, abandoned syntax, prototype adapters and narrower test
coverage.

- [V3 reference](../spec-grammar-v3.md) and [V3 authoring](../authoring-v3-patterns.md)
  document the retired text language. The current executable rejects it.
- [Old authoring roadmap](../authoring-roadmap.md) and
  [intent screenplays](../intent-screenplays.md) record earlier goals.
- [Composition and strobe investigations](../exploration/README.md) explain the
  initial exploration and its limits.
- [V4 development record](../exploration/v4/README.md) links the paired reviews,
  comparisons and original adapter. None of those adapters is on the player path.

Retired parser/compiler oracles, translation prototypes and their tests have
been deleted. Historical documents describe earlier investigations; referenced
implementations and test scripts may exist only in Git history.
