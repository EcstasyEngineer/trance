How composition behaves

Parallel patterns run their children together. Sequential patterns run children in order. Random patterns run one selected child at a time, with random or round-robin selection.

Every pattern can contain any other pattern. Duration, cadence, repeat, ramp and offset are properties of these three types. Chance exits belong to children of a random pattern.

Either chooses a theme randomly on selection; Alternate switches themes on selection. Neither is a clock. Animation media still comes from the shared stream.

No animation or flashing preview runs here. Native compiler validation does not verify GPU output or decoded media.
