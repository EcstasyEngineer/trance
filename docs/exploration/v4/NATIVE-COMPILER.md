# Native V4 compiler

The production V4 parser reads the canonical JSON AST directly into native
occurrence nodes and render statements. It does not generate or parse V3 text.
The three occurrence modes share one scheduler: parallel advances every unfinished
child, sequential advances the next child after completion, and random selects
one child according to its selection policy and exit rules. A finite short child
remains inactive after completion until its owning cadence or repetition restarts.

Each image output owns a private captured image, including when several image
outputs belong directly to the same parallel node. `either` resolves one theme
side per selection attempt and shares that side with its animation load. Animation
accent counters belong to authored outputs and survive cadence, ramp-segment and
scene re-entry; rendering a second output pass does not advance those counters.
Text and animation still use the engine's shared media channels. Native occurrence
composition does not turn those channels into independently decoded streams.

## Clocks

`local` curves use the current cadence interval, ramp segment, or occurrence when
there is no cadence. `scene` uses the root occurrence. An authored ancestor ID
uses that ancestor's occurrence progress, independently of its cadence. These
clock references remain structured in the authored JSON; internal render
expressions and clock aliases are generated by the compiler.

Offsets shift the local phase with effects suppressed during pre-roll. They do
not select images early. A root duration must be finite; a nested bounded
occurrence may repeat forever until its owner clips it. A sampled duration is
sampled when the occurrence is entered, with inclusive aligned endpoints.

## Input bounds and diagnostics

Native compilation rejects unsupported or misspelled fields, duplicate JSON
members, duplicate IDs, reserved clock aliases and references to non-ancestor
clocks. Diagnostics identify the relevant AST path.

- Source size: four MiB; node nesting: 64 levels; JSON nesting: 256 levels.
- Children per occurrence: 4,096; scalar nesting: 32; sum terms: two through eight.
- Frame quantities, repeat counts and rational components: at most 2,147,483,647.
  Finite duration times repeat count must fit that same range.
- Scalar literals must be finite and between -1e30 and 1e30.
- Ramp steps: at most 65,536, with at least one frame per step.
- Phase pre-roll: at most one million frames. Offset ramp or sampled spans above
  that bound can be conservatively rejected; there is no unproven fast-forward
  shortcut for nested scheduling.
- Decimal probabilities have at most six decimal places. Use
  `{"numerator":1,"denominator":3}` for a probability that needs an exact rational
  representation. Zero and one retain their exact meanings.

These are native execution limits. The earlier experimental Python validator and
JSON schema document the structural model; acceptance there alone does not imply
that an input is within the native compiler's resource bounds.

## V4-only product and builtin identity correction

The executable accepts V4 JSON exclusively. F2 source display/copy, new custom
patterns, live lint, CLI and session custom patterns share the same V4 frontend.
Historical V3 parsers, schedulers and comparison tests have been deleted. Existing V3 source receives an explicit unsupported diagnostic.

Parallel (#5) is restored to primary and secondary image lanes: each64f, secondary
offset32f and opacity0.5, zoom0to0.5, animation every third selection. The old
one-image definition came from a historical removal, not a swap with Flash Text.
Flash Text (#4) stays a two-image dissolve; Super Parallel (#6) stays three layers.
See [the identity audit](PARALLEL-IDENTITY-AUDIT.md).

V4 animation rendering now follows each image output's own captured theme side.
A later sibling load no longer redirects a primary output into the secondary
streamer. Same-side animations continue sharing that side's player. Native tests
cover both theme sides simultaneously, offsets/opacity, and repeated render passes.
